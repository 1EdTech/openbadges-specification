## TrustEd Credential Metadata Practices

Open Badges 3.0 supports rich metadata that enables learners, employers, educational institutions, workforce systems, and other third parties to better understand the purpose, rigor, and quality of an achievement credential.

The TrustEd Credential Profile defines additional requirements and recommendations for inclusion of specific Open Badges 3.0 metadata properties. The following guidance describes recommended practices for populating TrustEd Credential metadata in ways that improve transparency, interoperability, portability, machine readability, and trust.

This implementation guidance does not define the normative conformance requirements for the TrustEd Credential Profile. Implementers should refer to the TrustEd Credential Profile specification for required properties and conformance expectations.

Issuers implementing the TrustEd Credential Profile are encouraged to structure credential metadata in ways that:
- support interpretation by parties outside the issuing organization;
- improve portability across systems and platforms;
- increase comparability between credentials;
- support machine readability and automated processing; and
- communicate the rigor and context associated with an achievement.
